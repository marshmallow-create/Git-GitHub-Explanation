01 / FIRST THINGS FIRST

GitとGitHub、
何が違うの？

名前は似ていますが、役割は別々。まずはここを押さえれば、その後の操作がぐっとわかりやすくなります。

01 — LOCAL⌁

Git ギット

パソコンの中で、ファイルの変更履歴を記録する道具。

作成修正完成

たとえるなら 「いつ、何を変えたか」が残るセーブ機能

+
02 — ONLINE◎

GitHub ギットハブ

Gitで記録したプロジェクトをネット上に置いて共有するサービス。

●☁●

たとえるなら 作品を置いて、仲間と一緒に作業できる場所

!

まず覚えること Gitは「記録する仕組み」、GitHubは「記録を共有する場所」。GitはGitHubがなくても使えます。

02 / SEE THE BIG PICTURE

変更が届くまでの、
4つの場所。

書いたコードはすぐにGitHubへ行くわけではありません。どこに何があるかを、まず図でつかみましょう。

01▤作業フォルダファイルを編集する場所
git add→
02☑ステージング記録する変更を選ぶ
git commit→
03◉ローカル自分のPCに履歴を保存
git push→
04☁GitHubネット上で共有する

↶ GitHub側の変更を取り込むときは git pull を使います。

03 / LET'S TRY IT

最初の一歩を、
手を動かして。

ターミナル（コマンドを入力する画面）で、プロジェクトのフォルダを開いてから順番に実行してみましょう。

✳コマンドの読み方
$ は入力位置を示す記号です。コピーされるのはコマンド部分だけです。
01

Gitを使い始める

準備

今いるフォルダをGitで管理できるようにします。

$git init
02

変更の状態を見る

確認

追加・変更されたファイルがあるかを確かめます。迷ったらまずこれ。

$git status
03

記録する変更を選ぶ

選択

index.html を次の記録に含めます。ファイル名は自分のものに置き換えてください。

$git add index.html
04

変更を記録する

保存

何をしたか短いメッセージをつけて、履歴に残します。

$git commit -m "最初のページを作成"

04 / COMMAND CHEAT SHEET

まず覚えたい、
基本のコマンド。

全部を暗記する必要はありません。目的から探して、使うたびに少しずつ慣れていきましょう。

8 COMMANDS
準備01

管理を始める

今のフォルダにGitの記録場所を作る。

git init
確認02

現在の状態を見る

変更済み・選択済みのファイルを確認する。

git status
選択03

変更を選ぶ

指定したファイルを次の記録に含める。

git add index.html
保存04

履歴に記録する

選んだ変更に説明を付けて保存する。

git commit -m "説明"
確認05

履歴を見る

これまでの記録を新しい順に表示する。

git log --oneline
取得06

プロジェクトをコピー

GitHub上のプロジェクトをPCに持ってくる。

GitHub上の新しい変更をPCへ取り込む。

git pull

i URL はGitHubのリポジトリURL、index.html は実際のファイル名に置き換えます。git push と git pull は共有先の設定が済んでから使います。

コマンドを分解git add index.html

git add は変更を選ぶ操作。index.html は対象のファイル名です。

メッセージを付けるgit commit -m "説明"

-m の後には、何を変えたかがわかる短い説明を書きます。

05 / WORK TOGETHER

GitHubで、
つくるを共有する。

GitHubではプロジェクトの置き場所をリポジトリと呼びます。変更を送ったり、仲間の変更を受け取ったりできます。

↑push自分の記録を送る
↓pull新しい記録を受け取る
TEAM WORKFLOW⌘
main 共有する本線
feature 自分の作業
Pull request ↗
✳

ブランチは作業を分ける道。Pull requestは「この変更を本線に取り込みたい」と相談する機能です。

自分の新しいプロジェクトを公開するとき

最初の1回だけ、共有先を登録。

GitHubで空のリポジトリを作成し、表示されたURLを使います。ローカルで最初のcommitを作ってから実行してください。

git branch -M main作業中のブランチ名をmainにする
git remote add origin URLGitHubのURLを共有先として登録
git push -u origin main初回の変更をGitHubへ送る

THE TAKEAWAY

迷ったら、この順番。
